Seguridad en RunCircuit

En RunCircuit buscamos proteger la información de nuestros usuarios mediante prácticas razonables de seguridad, autenticación y control de acceso.

Última actualización: 4 de septiembre de 2026
Contenido 1. Nuestro compromiso 2. Autenticación 3. Protección de los datos 4. Controles de acceso 5. Infraestructura 6. Integraciones externas 7. Seguridad de la cuenta 8. Incidentes de seguridad 9. Reportar un problema

1. Nuestro compromiso

RunCircuit procura aplicar medidas técnicas y organizativas razonables para proteger la información de sus usuarios frente a accesos no autorizados, pérdida, modificación, uso indebido o divulgación.

La seguridad forma parte del desarrollo de la plataforma y se revisa a medida que RunCircuit incorpora nuevas funciones e integraciones.

2. Autenticación

El acceso a las funciones privadas de RunCircuit requiere una cuenta de usuario autenticada.

La autenticación de usuarios se gestiona mediante servicios especializados de infraestructura.

Contraseñas

RunCircuit no necesita mostrar ni almacenar contraseñas en texto visible dentro de la aplicación.

3. Protección de los datos

La información almacenada por RunCircuit se organiza mediante mecanismos de control de acceso destinados a limitar qué datos puede consultar o modificar cada usuario.

Dependiendo de la función utilizada, determinada información puede ser privada, visible únicamente para el usuario, o compartida con otros corredores cuando forma parte de funciones comunitarias.

4. Controles de acceso

RunCircuit utiliza reglas de acceso destinadas a separar la información de cada cuenta y controlar qué operaciones pueden realizar los usuarios.

Algunas funciones administrativas están disponibles únicamente para usuarios autorizados.

Las funciones comunitarias pueden mostrar información pública o compartida cuando ello resulte necesario para rankings, participación en carreras, perfiles públicos o conexiones entre corredores.

5. Infraestructura tecnológica

RunCircuit utiliza servicios tecnológicos de terceros para operar determinadas funciones de la plataforma.

Supabase

Actualmente RunCircuit utiliza Supabase para funciones relacionadas con autenticación, almacenamiento y gestión de datos.

El uso de estos servicios permite aprovechar mecanismos especializados de infraestructura, autenticación y seguridad.

6. Integraciones con servicios externos

RunCircuit puede incorporar integraciones con plataformas externas para ofrecer nuevas funciones a sus usuarios.

Garmin

Integración prevista

La sincronización automática con Garmin todavía se encuentra en desarrollo.

Cuando esta función se encuentre disponible, la conexión se realizará únicamente después de la autorización del usuario.

RunCircuit no solicitará la contraseña de Garmin y utilizará los mecanismos de autorización proporcionados por dicho servicio.

Solo se accederá a la información necesaria para las funciones de sincronización habilitadas.

7. Seguridad de la cuenta del usuario

La seguridad de RunCircuit también depende de las buenas prácticas de cada usuario.

Recomendamos:

  • Utilizar una contraseña segura.
  • No compartir credenciales de acceso con otras personas.
  • Proteger el dispositivo donde se utiliza RunCircuit.
  • Mantener actualizado el sistema operativo del dispositivo.
  • Cerrar sesión cuando se utilicen dispositivos compartidos.
  • Informar cualquier actividad sospechosa en la cuenta.

8. Incidentes de seguridad

Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

En caso de detectar un incidente que pueda afectar la seguridad de RunCircuit o la información de sus usuarios, se analizará el problema y se adoptarán las medidas razonables necesarias para reducir su impacto.

Cuando resulte necesario, se podrá informar a los usuarios afectados sobre las acciones que deban realizar.

9. Reportar un problema de seguridad

¿Encontraste un posible problema?

Si detectás una vulnerabilidad, comportamiento extraño o posible problema de seguridad, agradecemos que lo informes de manera responsable.

Para ayudarnos a analizar el problema, es útil incluir información como:

  • Una descripción clara del problema.
  • Los pasos necesarios para reproducirlo.
  • Capturas de pantalla, cuando correspondan.
  • La versión de RunCircuit utilizada.
  • El dispositivo o navegador donde ocurrió.

Por favor, evitá publicar vulnerabilidades o información sensible de otros usuarios mientras el problema está siendo investigado.
